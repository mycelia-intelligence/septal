Citing
======

If you use septal in academic work, please cite it:

.. code-block:: bibtex

   @software{septal,
     author  = {Mowbray, Max},
     title   = {septal: Parametric nonlinear programming with JAX},
     year    = {2026},
     url     = {https://github.com/mycelia-intelligence/septal},
     version = {0.3.0},
     license = {MIT}
   }

Set ``version`` to the release you used
(``python -c "import septal; print(septal.__version__)"``).

The same metadata is in ``CITATION.cff`` at the root of the
`repository <https://github.com/mycelia-intelligence/septal>`_, which GitHub exposes
through the "Cite this repository" button.
